# 🛒 E-Commerce Platform

A frontend-based e-commerce website developed as a collaborative software development project.

This project simulates a real-world company development environment where requirements are managed using Jira, source code is managed using Git and GitHub, development is performed through feature branches, changes are reviewed using Pull Requests, and the application is automatically tested and deployed using CI/CD.

---

## 📌 Project Overview

The **E-Commerce Platform** is a simple and user-friendly online shopping website.

The application provides multiple independent modules that together create a complete e-commerce experience.

The project is intentionally kept frontend-only so that the primary focus remains on:

- Team collaboration
- Jira task management
- Git and GitHub
- Branching
- Pull Requests
- Code Reviews
- CI/CD
- Automated Deployment

---

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Jira
- GitHub Actions
- GitHub Pages

---

## 🚫 Project Limitations

This project is a **frontend-only application**.

The following are not required:

- Backend
- Database
- REST API
- External APIs
- localStorage
- Real authentication
- Real payment gateway

Where data is required, developers should use **mock or predefined data in JavaScript**.

# 🎯 Features & Requirements

## 1. 🔐 Login & Registration

Create a simple Login and Registration interface.

### Requirements

- Login form
- Email field
- Password field
- Registration form
- Name field
- Email field
- Password field
- Confirm password field
- Forgot password UI
- Remember me option
- Basic form validation
- Error messages
- Success messages

### Expected Result

Users should be able to interact with the login and registration interface.

Actual authentication is not required.

---

## 2. 🏠 Home Page

Create an attractive homepage for the e-commerce website.

### Requirements

- Website logo and branding
- Hero section
- Promotional banner
- Welcome section
- Shop Now button
- Featured section
- Popular categories
- Special offers
- Benefits section
- Footer

### Expected Result

The homepage should provide users with an attractive introduction to the e-commerce website.

## 3. 🛒 Shopping Cart

- Display cart items

- Product price

- Decrease quantity
